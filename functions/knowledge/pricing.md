# Pricing

Acme Cloud has three plans:

- Free: $0 per user / month. Up to 3 users and 5 GB of storage. Core file sharing
  and search.
- Pro: $9 per user / month. Unlimited users, 1 TB of storage, versioning, and
  expiring share links.
- Business: $19 per user / month. Everything in Pro plus advanced access control,
  audit logs, and priority support.

All paid plans include a 14-day free trial, no credit card required. Annual billing
saves about 15% versus monthly.
