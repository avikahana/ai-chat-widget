Acme Cloud

A demo page for the grounded AI chat widget. Click the bot in the corner (or the button below) and ask about the product, pricing, or getting started. The assistant answers only from the knowledge base in functions/knowledge/.

⚙️ The widget POSTs to /api/chat, so answers require the Cloud Function running (deployed, or via the Firebase emulator with an Anthropic key). Without a backend the widget loads fine but shows a friendly error on send. See the README for setup.
