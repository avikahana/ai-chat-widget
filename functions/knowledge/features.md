# Features

- Secure workspaces: every team gets an encrypted workspace for its files.
- Granular sharing: share a single file or a whole folder, with view-only or
  edit access, and links that can expire.
- Fast search: full-text search across documents, including the contents of PDFs.
- Versioning: every file keeps its change history so you can roll back.
- Integrations: connect Acme Cloud to the tools your team already uses.

Acme Cloud runs in the browser and as desktop apps for macOS and Windows.
